# Trabajo Aplicativo - Grupo 4

## Proyecto

Generación y análisis de datos económicos mediante Python y R.


En esta etapa se generaron datos económicos simulados para cinco departamentos del Perú utilizando Python y NumPy.

## Departamentos

- Lima
- Arequipa
- Cusco
- Piura
- La Libertad

## Variables generadas

- Población
- Ingreso promedio mensual
- Número de hogares
- Actividad económica predominante

## Período

2020 - 2024

## Semilla utilizada

72641

## Archivos

- `python/generacion_datos.py`: programa utilizado para generar los datos.
- `data/datos_economicos.csv`: archivo CSV con los datos económicos simulados.
- `R/analisis_datos.R`: archivo destinado al análisis de los datos en R.
